# Keybinds & Shortcuts


## Shell Keybinds


### Main Functions


| Key Combo| Function|
|---|---|
| Super + Q | Close/Exit/Quit Window |
| Super + Space | Menu |
| Super + Escape | System Menu |
| Super + S | Toggle Scratch Pad |
| Super + Alt + S | Send Window to Scratch Pad |
| Super + O | Toggle Pop Out & Pin |

### Window Group (Holds 5 Windows)


| Key Combo | Function |                         |
|---|---|
| Super + / | Toggle Window Group |
| Super + Shift + / | Move Window out of Group |
| Super + > | Next Window in Group |
| Super + < | Previous Window in Group |
| Super + Shift + > | Move Group Right |
| Super + Shift + < | Move Group Left |
| Super + Ctrl + > | Add Window to Group at the Right | 
| Super + Ctrl + < | Add Window to Group at the Left |
