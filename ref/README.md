## Reference Documents

A place to store reference materials for this project.

### Documents of interest
1. dependency-info.md - This file contains information about the dependancies required for building and installing the desktop environments.
2. packaged-software.md - This file contains information about the packaged software that will be installed on the system.
3. variables.md - This file contains information about the variables used in the scripts.
4. keybinds.md - This file contains information on the default keybind for all desktop environments and applications installed on the system.
