## Scripts Directory

This folder contains module files for installing and setting up various features of the Practical Wayland environments.
*These files are not intended to be run independently.*

### 00-script.sh

A loop monitoring script that exits on completion of a background task.
**For Future Development**

### 01-script.sh

Sets up directory structure and installs base variables for scripts. Downloads the Practical Wayland repository and moves the files to the correct location. 

### 02-script.sh

Configures Debian Forky repositories and updates the system to Debian Forky.

### 03-script.sh

Installs development tools (Rust, Cargo, and Just) for the build environment in the current user's home directory.
